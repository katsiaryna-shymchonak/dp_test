# Пайплайн прогнозирования спроса 

Модульный пайплайн прогнозирования спроса, разработанный для розничных сетей. Пайплайн выполняет автоматическую очистку истории продаж, устраняет дефекты данных («призрачные» остатки, дефицит/OOS), динамически сегментирует товарный портфель с помощью матрицы ADI / $\text{CV}^2$, логирует выбор маршрутизации моделей и генерирует прогноз на 3 месяца вперед с помощью 50/50 статистического ансамбля (Holt-Winters / TSB + Seasonal Naïve).
